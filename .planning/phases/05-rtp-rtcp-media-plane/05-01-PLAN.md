<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 用户编码器 -> media API | 用户提交编码后的 Opus/H264 bytes，库负责复制和校验 |
| media executor -> network executor | 明文 RTP/RTCP 在固定槽中跨 executor 投递 |
| network executor -> observer.on_datagram | 只有 SRTP/SRTCP protect 成功后才能输出 datagram |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | media frame input | mitigate | kind、data、data_len 和容量全部校验，非法输入返回稳定 status |
| T-05-02 | Information Disclosure | cross-executor packet slot | mitigate | 明文 RTP/RTCP 只存在内部固定槽，后续计划必须 protect 成功才输出 |
| T-05-03 | Denial of Service | media queue | mitigate | queue 满返回容量错误并增加 `media_queue_full` |
</threat_model>
