# Phase 6 Plan 06: v1 总验收脚本、文档与测试收口

<objective>
把 Phase 6 产物收束为 v1 可运行验收入口：提供 `scripts/verify-v1.sh`，默认执行 CMake build、CTest、host Chrome E2E，显式 `--turn-config` 时执行 TURN relay E2E；更新 README/ROADMAP/STATE/REQUIREMENTS/SOURCE-MANIFEST，确保输出能区分构建、协议测试、互通、DataChannel、TURN 和媒体流动失败层。
</objective>

<must_haves>
<truths>
- D-13: 默认 `ctest` 不被 Chrome/Node/TURN 依赖卡住。
- D-14: 总验收脚本覆盖 build、CTest、host Chrome E2E，并通过显式参数运行 TURN relay。
- D-15: 输出有 stage banner 和机器可读摘要。
- D-16: 根目录不变成 JS 项目，Playwright 依赖仍在 `tests/e2e/`。
- TEST-01 到 TEST-04: 协议单元测试和 E2E 测试命令清晰，失败层可区分。
</truths>
</must_haves>

<threat_model>
| Threat | Severity | Mitigation |
|--------|----------|------------|
| v1 验收脚本把 TURN 缺配置当成功 | HIGH | `--turn-config` 参数存在时 TURN spec 必跑且缺配置非零；参数不存在时 summary 标记 `chrome_turn.skipped: true`。 |
| 文档把未运行的 TURN relay 标记完成 | HIGH | README/STATE/ROADMAP 区分 host default 与 TURN opt-in；完成标记只在真实命令通过后更新。 |
| 测试输出无法定位失败阶段 | MEDIUM | `verify-v1.sh` 和 `summary.js` 固定 stage names 和 JSON schema。 |
</threat_model>
