<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Remote SDP -> local JSEP summary | 信令侧提供的 fingerprint 可能被篡改 |
| DTLS peer certificate -> core verifier | backend 提供的 peer certificate fingerprint 必须与 SDP 绑定 |
| Backend local fingerprint -> SDP writer | 本地证书 fingerprint 必须进入 SDP，避免字符串配置与证书脱节 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Spoofing | SDP fingerprint / DTLS certificate | mitigate | 完整匹配 `sha-256 XX:...`，mismatch 进入 `dtls.failed` |
| T-04-07 | Tampering | `createOffer/createAnswer` fingerprint source | mitigate | 写 SDP 前查询 backend local fingerprint，覆盖旧 create-time 字符串 |
| T-04-08 | Elevation of Privilege | unsupported fingerprint algorithm | mitigate | 只接受 `sha-256`，其他算法返回 protocol/backend 错误 |
| T-04-09 | Information Disclosure | mismatch continuation | mitigate | mismatch 后禁止 key export 和 SRTP init |
| T-04-10 | Repudiation | fingerprint failure diagnostics | mitigate | observer error、trace reason `fingerprint_mismatch`、counter 同时记录 |
</threat_model>
