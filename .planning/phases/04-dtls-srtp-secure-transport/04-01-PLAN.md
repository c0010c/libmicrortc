<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 核心库 -> security backend | 核心把 DTLS bytes、storage 和角色交给可插拔 backend |
| security backend -> 核心事件回调 | backend 通过 event callback 交回 outgoing datagram、handshake complete 或 backend error |
| 核心库 -> `observer.on_datagram` | 核心把 backend outgoing datagram 转交给用户 UDP/socket 层 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | backend datagram output | mitigate | backend 只能发 `RTC_SECURITY_BACKEND_EVENT_OUTGOING_DATAGRAM`，由核心统一转 `observer.on_datagram` |
| T-04-02 | Tampering | handshake-complete signal | mitigate | 使用 `RTC_SECURITY_BACKEND_EVENT_HANDSHAKE_COMPLETE` 作为唯一 handshake complete 跨层信号，后续计划在核心中触发 fingerprint verify/key export |
| T-04-03 | Denial of Service | backend session storage | mitigate | vtable session 只接收 create-time fixed storage，容量不足走 `RTC_CAPACITY_RESOURCE_DTLS_SESSION` |
| T-04-04 | Repudiation | security errors | mitigate | 预置 detail code、trace reason、counter 承载细粒度失败原因 |
</threat_model>
