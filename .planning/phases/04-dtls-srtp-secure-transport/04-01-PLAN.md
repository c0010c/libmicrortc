<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 用户 UDP -> `rtc_peer_connection_receive_datagram` | 不可信网络 datagram 进入核心库 |
| 核心库 -> security backend | 核心把 DTLS bytes、storage 和角色交给可插拔 backend |
| security backend -> `observer.on_datagram` | backend 产生的 DTLS bytes 通过用户拥有的 UDP/socket 发送 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Spoofing | `rtc_security_handle_dtls_datagram` | mitigate | ICE 未 connected/selected 时返回 `RTC_STATUS_INVALID_STATE`，trace reason `ice_not_connected`，不缓存早到 DTLS |
| T-04-02 | Tampering | `rtc_security_on_ice_connected` | mitigate | DTLS role 由 SDP setup 与 JSEP/ICE role 推导，不接受用户手动 role override |
| T-04-03 | Information Disclosure | `observer.on_datagram` path | mitigate | 只通过既有 `observer.on_datagram` 输出 DTLS bytes，库/backend 不创建 socket |
| T-04-04 | Denial of Service | backend session storage | mitigate | create-time 固定 storage，容量不足返回容量错误，不允许运行期动态增长 |
| T-04-05 | Repudiation | security errors | mitigate | 所有 backend/start/input 失败输出 observer error、trace reason 和 counter |
</threat_model>
