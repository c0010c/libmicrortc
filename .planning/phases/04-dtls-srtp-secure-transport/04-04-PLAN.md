<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Backend failure -> public API | 第三方/测试 backend 错误不能污染稳定 public status |
| Security diagnostics -> observer/trace/counter | 细粒度安全原因需要可诊断但不能扩大 API 枚举面 |
| Documentation -> downstream implementers | 文档错误会导致 Phase 5 泄漏明文或依赖真实库 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-16 | Repudiation | backend error mapping | mitigate | observer detail code、trace reason、counter 三路记录 |
| T-04-17 | Tampering | public `rtc_status_t` | mitigate | 禁止新增细粒度 DTLS/SRTP public status，保持粗粒度稳定 |
| T-04-18 | Information Disclosure | docs / Phase 5 handoff | mitigate | 文档明确 protect 失败不得输出明文，unprotect 失败不得输出未认证媒体 |
| T-04-19 | Denial of Service | optional real backend | mitigate | 默认构建不依赖 OpenSSL/libsrtp，真实适配必须可选并说明固定 storage |
| T-04-20 | Spoofing | validation matrix | mitigate | deterministic backend 覆盖 fingerprint mismatch、handshake error、key export failure、protect/unprotect failure |
</threat_model>
