<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DTLS handshake complete event -> SRTP key export | backend 事件触发核心安全状态转换 |
| RTP/RTCP plaintext -> SRTP/SRTCP protect wrapper | Phase 5 内部媒体数据进入保护边界 |
| SRTP/SRTCP ciphertext -> unprotect wrapper | 未认证网络数据进入媒体层前的认证边界 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-11 | Tampering | key export | mitigate | 只在 `RTC_SECURITY_BACKEND_EVENT_HANDSHAKE_COMPLETE` 后执行 fingerprint verification，再使用 `EXTRACTOR-dtls_srtp` 导出 |
| T-04-12 | Information Disclosure | SRTP protect failure | mitigate | protect 失败不调用 `observer.on_datagram`，reason `srtp_protect_failed` |
| T-04-13 | Tampering | SRTP/SRTCP unprotect failure | mitigate | unprotect 失败不调用媒体输出，不输出未认证数据 |
| T-04-14 | Denial of Service | protect capacity | mitigate | wrapper 接收 `capacity` 并在调用 backend 前检查输出空间 |
| T-04-15 | Spoofing | replay/auth failure | mitigate | backend replay/auth failure 映射为 `srtp_replay_failed` 或 unprotect failed counter/trace |
</threat_model>
