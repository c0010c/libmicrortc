<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 用户 UDP -> `rtc_peer_connection_receive_datagram` | 不可信网络 datagram 进入核心库 |
| 核心库 -> security backend | 核心把 DTLS bytes、storage 和角色交给可插拔 backend |
| security backend event -> `observer.on_datagram` | backend 产生的 DTLS bytes 由核心转交给用户 UDP/socket 发送 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05 | Spoofing | `rtc_security_handle_dtls_datagram` | mitigate | ICE 未 connected/selected 时返回 `RTC_STATUS_INVALID_STATE`，trace reason `ice_not_connected`，不缓存早到 DTLS |
| T-04-06 | Tampering | `rtc_security_on_ice_connected` | mitigate | DTLS role 由 SDP setup 与 JSEP/ICE role 推导，不接受用户手动 role override |
| T-04-07 | Information Disclosure | `observer.on_datagram` path | mitigate | 只通过既有 `observer.on_datagram` 输出 DTLS bytes，库/backend 不创建 socket |
| T-04-08 | Repudiation | security errors | mitigate | 所有 backend/start/input 失败输出 observer error、trace reason 和 counter |
</threat_model>
