# Phase 4 Plan 04: DTLS OpenSSL 握手、Fingerprint 校验与 SRTP Session

<objective>
把 DTLS OpenSSL session 接到 ICE selected pair 上，从 SDP `setup` 推导角色，完成 handshake、校验远端 fingerprint、导出 SRTP keying material，并创建 libsrtp transmit/receive session。Phase 4 只验证安全通道初始化，不做真实 H264/Opus RTP 媒体流动。
</objective>

<must_haves>
<truths>
- D-07: 必须完成 DTLS OpenSSL 路径握手并导出 SRTP keying material。
- D-08: DTLS 角色必须从 SDP `setup` 属性推导。
- D-09: SDP answer 带 `a=fingerprint`，DTLS 握手时校验远端 fingerprint。
- D-10: Phase 4 需要用导出的 keying material 创建 SRTP session。
- D-11: 真实 RTP 包 SRTP protect/unprotect 属于 Phase 5。
</truths>
</must_haves>

<threat_model>
| Threat | Severity | Mitigation |
|--------|----------|------------|
| Fingerprint 未校验导致 MITM 风险 | HIGH | Add positive and negative remote fingerprint tests; connected state requires verify success. |
| Client/server SRTP keys reversed | HIGH | Role-aware key mapping test covers local active/passive roles. |
| DTLS packets bypass selected ICE pair | MEDIUM | Outbound DTLS callback must send through selected pair only and fail when no selected pair exists. |
</threat_model>
