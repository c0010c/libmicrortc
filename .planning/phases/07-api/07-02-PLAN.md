| Boundary | Description |

| whitelist rules -> compliance result | 分类规则会影响后续 Phase 8+ 是否认为 residual 合规。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | `scripts/scan-api-residuals.sh` | mitigate | Quote all variables, reject unknown options with exit 2, avoid `eval`, normalize repo-relative paths before use, and create report directory explicitly. |
| T-07-02 | Information Disclosure | `mrtc-ice-servers.local.json`, generated reports | mitigate | Exclude local TURN config by path; never print matched line text; report only path/line/symbol/category/reason; verification greps report for secret field names and test secret values. |
| T-07-03 | Repudiation | residual whitelist categories | mitigate | Every finding includes category, matched path, matched symbol, and source/whitelist reason; categories are finite and named in docs and script. |
</threat_model>
