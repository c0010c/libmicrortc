# Phase 6 Plan 05: TURN Relay E2E、Relay Stats 校验与 Secret Redaction

<objective>
实现显式 TURN relay Chrome E2E：读取本地 TURN 配置，强制 Chrome `iceTransportPolicy=relay`，启动同一 C answerer demo，证明 selected candidate path 是 relay，并覆盖连接、DataChannel、浏览器 H264/Opus inbound、C 端 H264/Opus inbound，同时确保所有日志和摘要不泄漏真实 TURN credential。
</objective>

<must_haves>
<truths>
- D-09: TURN 缺配置必须硬失败，不能 skip 后成功。
- D-10: 继续使用 `ice_servers`、`urls`、`username`、`credential`/`password` 字段；真实 secret 不写入仓库。
- D-11: Chrome 侧 `iceTransportPolicy=relay`，并通过 selected candidate pair/local candidate stats 校验 `candidateType=relay`。
- D-12: Relay 路径必须覆盖连接、DataChannel 和双向媒体。
</truths>
</must_haves>

<threat_model>
| Threat | Severity | Mitigation |
|--------|----------|------------|
| TURN 测试在缺配置时静默跳过 | HIGH | `turn-config.js` 缺文件、无 turn URL、无 credential 都非零失败。 |
| Relay 测试实际走 host/srflx | HIGH | Browser config 强制 `iceTransportPolicy: "relay"` 且 stats 校验 selected local candidate `candidateType=relay`。 |
| TURN secret 泄漏 | HIGH | Redaction helper 覆盖 config load、browser config echo、server logs、C demo events、summary artifact。 |
</threat_model>
